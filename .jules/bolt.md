## 2024-05-15 - Prisma Transactions and Promise.all\n**Learning:** Prisma fully supports `Promise.all` inside interactive transactions (`prisma.$transaction(async (tx) => {...})`). Using sequential `await` inside loops within transactions is an anti-pattern as it blocks the event loop unnecessarily.\n**Action:** Always prefer `await Promise.all(...)` for independent database operations inside a Prisma transaction to improve throughput and reduce transaction duration.
