## 2024-05-24 - React Context and Keystroke Re-renders
**Learning:** In React applications where rapid-updating state (like `searchQuery` typed by the user) is kept high up in the component tree (e.g., `Home.jsx`), it causes severe re-render cascades in all child components like the product grid. Components like `ProductCard` that consume multiple Contexts (`AuthContext`, `CartContext`) might seem difficult to memoize, but because these context values remain stable during typing, `React.memo` is highly effective.
**Action:** When placing search input state in a parent component that renders a large grid, always verify if the child cards are unnecessarily re-rendering on every keystroke, and apply `React.memo` to the child cards if their props and consumed context values are stable during the keystrokes.
